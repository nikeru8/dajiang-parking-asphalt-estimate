# 大江停車場柏油估算

[開啟估算網頁](https://nikeru8.github.io/dajiang-parking-asphalt-estimate/)

依中壢大江購物中心北側的兩份 CAD 圖面，估算車格、行車通道和出入口的鋪設面積。可勾選施作範圍，調整鋪設厚度、材料密度及損耗，輸入自己的單價後列印估算單。原圖區可切換全區平面配置圖與景觀底圖，也能下載個別 DWG。

| 圖面可估範圍 | 鋪設面積 |
| --- | ---: |
| 設計停車場的 39 格車位、中央車道與出入口 | 1,008.92 m² |
| 加上道路另一側的 172 格既有車位及推估的列間空帶 | 4,280.53 m² |

第二項已包含第一項。既有區兩端、外圈及出入口仍需丈量，正式報價應依發包範圍及現場確認。

## 離線使用

下載並解壓縮整份專案，再用瀏覽器開啟根目錄的 `index.html`。估算、圖面檢視及列印都可在本機使用。
