# 大江停車場柏油估算

[開啟估算網頁](https://nikeru8.github.io/dajiang-parking-asphalt-estimate/)

[開啟可列印原圖 PDF](https://nikeru8.github.io/dajiang-parking-asphalt-estimate/output/pdf/parking-original-drawings.pdf)

首頁直接列出只鋪設計停車場、兩區一起鋪的估算面積。點「看停車場原圖」可直接切到 39 格車位、對面 172 格車位或全區圖。點「列印原圖」可開啟五頁圖冊。

需要估料或報價時，點「算用料和費用」，選範圍、填柏油壓實厚度即可看備料噸數。單價、現場追加或扣除面積及材料密度可分別展開調整。估算單支援 A4 列印。

| 圖面可估範圍 | 鋪設面積 |
| --- | ---: |
| 設計停車場的 39 格車位、中央車道與出入口 | 1,008.92 m² |
| 加上道路另一側的 172 格既有車位及推估的列間空帶 | 4,280.53 m² |

第二項已包含第一項。既有區兩端、外圈及出入口仍需丈量，正式報價應依發包範圍及現場確認。

## 列印原圖

原圖 PDF 收錄兩份 DWG 內的出圖版面，另附兩張從景觀底圖放大的停車場詳圖。依各頁指定紙張，將列印比例設為「實際大小（100%）」。要在一般 A3 印表機查看車格，可只印第 3 至 4 頁。

| 頁次 | 圖面 | 紙張 | 圖上比例 |
| --- | --- | --- | --- |
| 1 | L01-05 全區平面配置圖 | A1 橫式 | 1:500 |
| 2 | LA-baseplan 景觀底圖原出圖視窗 | A1 直式 | 1:750 |
| 3 | 設計停車場 39 格放大圖 | A3 橫式 | 1:200 |
| 4 | 既有停車區 172 格放大圖 | A3 直式 | 1:400 |
| 5 | LA-baseplan「配置1」原始大範圍視圖 | A4 橫式 | 依原視窗 |

圖面依資料夾中能讀取的線條與標註出圖。原 CAD 另引用的圖框、部分測量底圖與專用列印樣式未隨檔提供，PDF 保留現有圖面並使用白底列印線色。

## 離線使用

下載並解壓縮整份專案，再用瀏覽器開啟根目錄的 `index.html`。估算、圖面檢視及列印都可在本機使用。
